# Pars Sport – Düsseldorf

Iranischer Sportclub Website – Next.js 14

## Quick Deploy to Vercel

### Option A – Vercel Dashboard (easiest)
1. Unzip this folder
2. Push to a GitHub repo
3. Import the repo on [vercel.com](https://vercel.com) → Deploy

### Option B – Vercel CLI
```bash
npm install -g vercel
cd pars-sport
npm install
vercel deploy
```

### Option C – Local dev
```bash
cd pars-sport
npm install
npm run dev
# → http://localhost:3000
```

## Stack
- **Next.js 14** (App Router)
- **React 18**
- Fonts: Playfair Display, Barlow Condensed, Barlow, Vazirmatn (Google Fonts)
- All images served from `/public/`
- Bilingual: German + Farsi (RTL)
